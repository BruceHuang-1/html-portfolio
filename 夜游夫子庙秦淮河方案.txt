            夜游夫子庙 · 秦淮河  游览方案
══════════════════════════════════════════════════════════════

  主题：十里秦淮 · 灯火夜色
  适宜季节：春、秋、初夏（天气凉爽，灯会更盛）
  建议时长：约 3.5～4.5 小时（黄昏至晚间）
  适合人群：情侣、亲子、朋友小团、摄影爱好者


──────────────────────────────────────────────────────────────
一、行程总览（推荐路线）
──────────────────────────────────────────────────────────────

  17:30  抵达夫子庙景区入口（建议从贡院街 / 瞻园路方向进入）
  17:45  漫步贡院街 · 感受市井烟火，拍黄昏街景
  18:15  参观江南贡院历史陈列馆 / 科举博物馆（可选）
  18:45  晚餐：老门东 / 夫子庙小吃街（鸭血粉丝、小笼、梅花糕等）
  19:40  步行至画舫码头，登船夜游秦淮河
  20:30  下船后沿河岸漫步，欣赏两岸灯影与古建夜景
  21:00  夫子庙大成殿外广场 · 孔庙夜景打卡
  21:20  乌衣巷 / 王谢故居一带轻走（可选）
  21:45  茶歇或买伴手礼，结束行程


──────────────────────────────────────────────────────────────
二、核心体验亮点
──────────────────────────────────────────────────────────────

  1. 秦淮河画舫夜游
     · 乘画舫穿行十里秦淮，两岸朱栏画栋、灯火倒映水面
     · 船上可听导览讲解：六朝金粉、桃花扇、李香君等故事
     · 推荐时段：开灯后约 19:30～21:00，光影最完整

  2. 夫子庙夜景
     · 大成殿、棂星门、牌坊在夜灯下金碧辉煌
     · 广场人流热闹，适合合影与短视频拍摄

  3. 美食与市井
     · 秦淮八绝、盐水鸭、鸭血粉丝汤、鸡鸣汤包等
     · 老门东更偏居民区烟火气，相对不那么拥挤

  4. 人文小巷
     · 乌衣巷、桃叶渡、李香君故居——把诗句变成眼前的夜色


──────────────────────────────────────────────────────────────
三、详细分段说明
──────────────────────────────────────────────────────────────

【A. 黄昏入场 · 17:30–18:45】

  建议入口：瞻园路 / 贡院西街一带，人流相对可控。
  步行重点：
    · 贡院街牌坊与街景（适合广角、人像）
    · 江南贡院（了解科举文化，室内参观约 30～40 分钟）
  贴士：
    · 周末与节假日人多，尽量错开 18:00 前高峰；
    · 若只想轻松散步，可跳过馆内，直接找餐厅排队。


【B. 晚餐 · 18:45–19:40】

  推荐方向（按偏好选一）：

  · 正宗本地风味：老门东（步行约 10～15 分钟）
      例：鸭血粉丝、小碗菜、盐水鸭、糖芋苗
  · 便捷小吃打卡：夫子庙小吃街 / 贡院街周边
      例：梅花糕、赤豆元宵、小笼包、豆腐涝
  · 稍正式一点：瞻园路沿线中餐厅（适合请客或家庭用餐）

  用餐节奏建议：
    控制在 50 分钟内结束，预留步行到码头与购票时间。


【C. 画舫夜游秦淮河 · 19:40–20:30】

  码头参考：夫子庙画舫码头（具体以当日现场公告为准）
  船票：现场或官方渠道提前购票更稳妥；旺季建议预约
  航程：约 40～50 分钟（视线路而定）

  船上体验建议：
    · 尽量选靠窗 / 靠舷座位，便于拍照
    · 关闭闪光灯，用夜景模式拍灯影倒影
    · 留意两岸：文德桥、白鹭洲方向、秦淮风光带古建筑群

  注意事项：
    · 开船前 10～15 分钟到达码头
    · 雨天穿防滑鞋，注意甲板潮湿
    · 儿童需有成人陪同，注意安全


【D. 河岸夜漫步 · 20:30–21:20】

  下船后推荐步行环线（可按体力加减）：

    码头 → 文德桥附近观灯 → 夫子庙大成殿外广场
         → （可选）乌衣巷 / 李香君故居外围
         → 返回小吃街或地铁站

  拍照点提示：
    · 文德桥：经典“秦淮灯影”构图
    · 大成殿前广场：牌坊与夜灯对称构图
    · 河岸栏杆：人像剪影 + 水面光斑


【E. 收尾 · 21:20–22:00】

  · 买伴手礼：盐水鸭、鸭油酥烧饼、雨花茶、工艺灯笼小礼品
  · 茶歇：咖啡馆 / 茶馆稍坐，避开人流高峰再离场
  · 返程：地铁、网约车均可；周末夜间打车可能需多等几分钟


──────────────────────────────────────────────────────────────
四、交通与到达
──────────────────────────────────────────────────────────────

  地铁：
    · 3 号线「夫子庙」站（出站步行即达景区核心区）
    · 亦可结合 1 号线「三山街」站再步行前往

  自驾 / 网约车：
    · 景区周边停车紧张，尤其周末晚间
    · 建议地铁 + 步行，或停远一点再步行入场

  内部步行：
    · 全程以步行为主，穿舒适平底鞋
    · 预计步行量：约 4～6 公里（含河岸漫步）


──────────────────────────────────────────────────────────────
五、预算参考（人均，人民币）
──────────────────────────────────────────────────────────────

  项目                预估区间
  ────────────────────────────────
  景区相关门票/场馆    0～50 元（视是否进馆）
  画舫夜游船票         约 60～120 元（线路与船型不同）
  晚餐                 50～120 元
  小吃 / 伴手礼        30～80 元
  交通（地铁往返）     约 6～12 元
  ────────────────────────────────
  合计参考             约 150～350 元 / 人

  * 旺季、节庆灯会、包船或升级船型会更高。


──────────────────────────────────────────────────────────────
六、最佳季节与天气建议
──────────────────────────────────────────────────────────────

  推荐：
    · 春季（3–5 月）：气温舒适，夜景清透
    · 秋季（9–11 月）：天高气爽，适合长线夜游
    · 春节 / 元宵灯会期间：灯彩最盛，但极度拥挤，需提前规划

  谨慎：
    · 盛夏午后闷热，建议再晚一点出门，并补水
    · 雨天可缩短户外段，以画舫 + 室内餐饮为主


──────────────────────────────────────────────────────────────
七、摄影与打卡清单
──────────────────────────────────────────────────────────────

  □ 贡院街黄昏街景
  □ 江南贡院牌坊 / 展陈细节
  □ 秦淮八绝或本地小吃特写
  □ 画舫甲板 + 两岸灯火
  □ 水面倒影（长曝光更佳）
  □ 夫子庙大成殿夜景全景
  □ 文德桥灯影构图
  □ 乌衣巷口街景（可选）


──────────────────────────────────────────────────────────────
八、实用贴士
──────────────────────────────────────────────────────────────

  1. 提前查当日开放时间、画舫航班与是否需预约。
  2. 节假日人流极大，建议错峰（工作日夜晚最佳）。
  3. 保管好随身物品；热闹街区注意防盗。
  4. 尊重文物与宗教场所规定，勿攀爬、勿大声喧哗。
  5. 带充电宝、轻便外套（河边夜间可能偏凉）。
  6. 有老人小孩时，压缩步行距离，优先画舫 + 广场打卡。
  7. 美食尽量选择明码标价、卫生口碑好的店铺。


──────────────────────────────────────────────────────────────
九、两套备选方案（按偏好切换）
──────────────────────────────────────────────────────────────

【方案甲｜经典灯影（本文件主推）】
  黄昏街景 → 晚餐 → 画舫 → 河岸 + 孔庙夜景
  适合：第一次来、想要“标准秦淮夜”的游客

【方案乙｜人文慢游】
  瞻园 / 王谢故居 / 李香君故居（白天或傍晚）
  → 老门东晚餐 → 短程河岸散步（可不坐船）
  → 茶馆夜坐
  适合：不赶景点、更爱历史与安静氛围的人

【方案丙｜摄影专线】
  提前踩点构图 → 开灯瞬间抢拍大成殿与河面
  → 画舫中段拍摄两岸 → 文德桥长曝光
  → 深夜人少后再补几张空镜
  适合：摄影爱好者（需更晚结束）
